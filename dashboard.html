Conectividad & Exportación API

Genere y administre credenciales seguras (API Key y Secreto) para que aplicaciones web externas puedan exportar el listado de estudiantes (Cédula y Nombre Completo) en formato JSON.

Endpoint Oficial de Integración JSON

Para consultar o sincronizar el listado de estudiantes desde cualquier otra web o servidor externo, realice una petición GET o POST con las credenciales creadas:

GET / POST/api/sgn?action=apiExportEstudiantes
Encabezados HTTP (Recomendado):
x-api-key: sgn_live_...
x-api-secret: sec_...
Parámetros en URL (Alternativa):
?action=apiExportEstudiantes
&api_key=...&api_secret=...
Formato de Retorno:
JSON con cedula y nombre_completo.
Soporta &raw=1 para array directo.

Ejemplos de Conectividad para Otras Webs
Soporte Multilenguaje 
# Ejemplo de llamada HTTP desde terminal o servidor externo
curl -X GET "https://tudominio.com/api/sgn?action=apiExportEstudiantes" \
  -H "x-api-key: TU_API_KEY" \
  -H "x-api-secret: TU_API_SECRET"
// Consumo directo desde el frontend o backend de otra web
const response = await fetch("https://tudominio.com/api/sgn?action=apiExportEstudiantes", {
  method: "GET",
  headers: {
    "x-api-key": "TU_API_KEY",
    "x-api-secret": "TU_API_SECRET"
  }
});

const data = await response.json();
if (data.success) {
  // Array de objetos: [{ cedula: "V-12345678", nombre_completo: "Juan Pérez" }, ...]
  console.log("Total estudiantes:", data.total);
  console.log("Estudiantes:", data.estudiantes);
}
import requests

url = "https://tudominio.com/api/sgn?action=apiExportEstudiantes"
headers = {
    "x-api-key": "TU_API_KEY",
    "x-api-secret": "TU_API_SECRET"
}

response = requests.get(url, headers=headers)
data = response.json()

if data.get("success"):
    for alumno in data.get("estudiantes", []):
        print(f"Cédula: {alumno['cedula']} | Nombre: {alumno['nombre_completo']}")
<?php
$url = "https://tudominio.com/api/sgn?action=apiExportEstudiantes";
$ch = curl_init($url);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "x-api-key: TU_API_KEY",
    "x-api-secret: TU_API_SECRET"
]);
$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
if (!empty($data['success'])) {
    foreach ($data['estudiantes'] as $alumno) {
        echo $alumno['cedula'] . " - " . $alumno['nombre_completo'] . PHP_EOL;
    }
}
?>
